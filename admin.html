Conectar el contador de visitas

Pegue su token de lectura de GoatCounter. Se guarda solo en este navegador.

¿Cómo obtengo el token?
  1. Abra cefrodyr.goatcounter.com/user/api e ingrese.
  2. Pulse Create new token.
  3. Marque solo el permiso de leer estadísticas (no escritura).
  4. Copie el token y péguelo arriba.
