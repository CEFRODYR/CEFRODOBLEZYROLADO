Ingresar

Pegue aquí su clave de acceso (token) de GitHub. Se guarda solo en este navegador.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Nombre: panel-cefro. Expiración: la más larga (1 año).
  3. En Repository access elija Only select repositories → cefrodoblezyrolado.
  4. En Permissions → Repository permissions → Contents elija Read and write.
  5. Pulse Generate token, copie el texto y péguelo abajo.
